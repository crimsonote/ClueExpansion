# 断电融毁：倒计时流速与自适应停钟

> 功能目录：`Features/Host/Meltdown/`（段 `[ClueMeltdown]`，默认启用）
> 入口：房主侧，无命令；断电时自动生效。

## 1. 口径

原版**断电不会加速倒计时**：`TimeManager.TickSurvive` 每秒固定 `RemainTime -= 1`。
但断电后白方做不了任务（任务需要电力 / 光照），等效于额外损失可用时间。

本功能把「断电期间剩余时间的流逝」做成可调项，并加一条自适应平衡规则：

- **流速**：断电期间按 `SpeedMultiplier` 扣减剩余时间（1 = 原版，2 = 更快，0.5 = 更慢，0 = 停钟）；
- **停钟**：最近 `RecentRounds` 局里「融毁胜利」（时间流空导致终局）的比例**严格大于**
  `RatioThreshold`（默认 30%）时，本局断电期间停钟；
- **告知**：停钟生效的局，在开局第 `NoticeSecond` 秒（默认 5）或出现「白转黑」后，
  通过秘密通道告知黑（Black）与黑幕（Dark）：
  「【断电融毁】近期融毁胜利比例大于 30%，本局断电时倒计时流逝将会暂停。」
- **互斥**：`HideAndSeekMode`（默认 `auto`）——捉迷藏模式启用（HideAndSeek 的 `[HS_Mode] Enabled`）时失效；
  只装插件但模式关着不影响本功能；`on` 强制启用、`off` 强制失效。

## 2. 挂点与实现

| 环节 | 位置 | 做法 |
| --- | --- | --- |
| 断电动⼒ | `DeviceManager.GetDisconnectFuseCount() >= 2` | 与 `Fusebox.DisconnetCable` → `ClearFuseboxSabotage` 同口径；每秒现读，不缓存断电事件 |
| 倒计时流逝 | `TimeManager.TickSurvive` 的 Prefix | 原方法随后 `RemainTime -= 1`；Prefix 先把值预调成 `remain - m + 1`，让原方法扣完并广播目标值 |
| 融毁胜利 | `GameRoom.GameOver` 的 Postfix | `RemainTime <= 0` 记为融毁胜利，否则记普通终局；每局只记一次 |
| 每局开始 | `GameRoom.ChangeGameState(Survive)` | 按历史比例决定 `PauseThisRound`，记录 `RoundStartSecond` |
| 告知时机 | `GameRoom.SurvivalTick` 的 Postfix | 每秒检查：开局第 N 秒 / 任意玩家 `White → Black|Dark` |
| 历史统计 | `BepInEx/config/ClueDetail.meltdown.txt` | 每行 `1`/`0`，保留最近 `RecentRounds` 局，跨重启保留 |

`RemainTime` 是 `{ get; private set; }`，写入走反射（`GetSetMethod(true)`）。

## 3. 配置

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `SpeedMultiplier` | 1 | 断电期间剩余时间倍率（0–5；0 = 停钟） |
| `PauseWhenOverRatio` | true | 比例超阈值时本局断电停钟 |
| `RecentRounds` | 10 | 统计最近多少局 |
| `RatioThreshold` | 0.3 | 比例阈值（严格大于） |
| `NoticeSecond` | 5 | 开局第几秒告知黑方（0 = 不告知） |
| `HideAndSeekMode` | auto | `auto` = 捉迷藏模式启用时失效；`on` = 强制启用；`off` = 强制失效 |
| `NoticeEnabled` | true | 是否发送开局 / 白转黑提示 |
| `NoticeText` | 固定文案 | 提示文案，`{ratio}` 替换为阈值百分比 |

全部热读；热关闭时 `OnDisabled` 清空本局状态（历史统计文件保留）。

## 4. 已知边界

- 客户端 `S_TIME` 的 `Remain` 是 `(int)`，浮点倍率（如 0.5）会被截断显示，但服务端真值按浮点推进；
  UI 数字可能跳 1。
- 停钟只在**断电期间**；修复一台电闸（`ConnetCable`，`GetDisconnectFuseCount` 回到 1）后恢复正常速度。
- 停钟不影响任务加时（`MissionManager.ClearMission` 的 `UpdateRemainTime` 是独立路径）。
- 与捉迷藏互斥是**模式级**判断：读 `BepInEx/config/HideAndSeek.cfg` 的 `[HS_Mode] Enabled`（5 秒缓存，热读），不是程序集级。
