## 1. 红色 `--:--` 的完整条件

调查阶段回放时间线上，某个槽位显示**红色 `--:--`**，需要同时满足：

| # | 条件 | 代码位置 |
|---|---|---|
| ① | 某具尸体 `CorpseMetaCache.IsReport == false`（未报告） | `TimelineManager.Rebuild` :35821 |
| ② | `TimelineMirror.TryGetHiddenWindow(...)` 成功 | :187157 |
| ③ | 该帧的时间 ∈ `_hidden`（**只有 3 个点**） | `CollectHidden` :187209 |
| ④ | `TimelineMirror.IsRegular(time)` 为 true（**硬编码 `% 10 == Offset`**） | :187200 |

```csharp
// Rebuild（:35812）
foreach (var meta in Managers.Game.CorpseMetas.Values)
{
    if (!meta.IsReport && TimelineMirror.TryGetHiddenWindow(meta.DeadTime, meta.VictimId, ...))
        TimelineMirror.CollectHidden(_hidden, meta.DeadTime, firstHidden);
}

foreach (int key in TimelineMirror.Frames.Keys)
{
    if (!_hidden.Contains(key))          _slots.Add(key);          // 正常
    else if (TimelineMirror.IsRegular(key)) { _slots.Add(key); _lost.Add(key); }  // --:--
    // 否则：帧直接消失
}

// LayoutLabels（:86314）
bool lost = Managers.Timeline.IsLostSlot(_slots[i]);
_labelRed[i] = lost || IsKill(_slots[i]);
text = lost ? "--:--" : FormatClock(_slots[i]);
```

`CollectHidden` 只加 **3 个具体时间点**，不是区间：

```csharp
public static void CollectHidden(HashSet<int> hidden, int deadTime, int firstHidden)
{
    hidden.Add(deadTime);
    hidden.Add(firstHidden);
    hidden.Add(firstHidden + 10);
}
```

`IsRegular` 硬编码 10：

```csharp
public static bool IsRegular(int time)
{
    if (Offset >= 0) return Mod(time - Offset, 10) == 0;
    return false;
}
```

## 2. 边界情况（具体例子）

### 例 A：原版 10 分钟网格，Offset = 3，尸体 deadTime = 47

`TryGetHiddenWindow`（:187157）里：

```text
num  = 10
num3 = 47 - Mod(47 - 3, 10) = 47 - 4 = 43
num3 != deadTime ⇒ firstHidden 从 {33, 43, 53} 里按 Pick(47, victimId, 0, 3) 选
```

假设选中 43：

| 帧 | 是否在 `_hidden` | `IsRegular` | 结果 |
|---|---|---|---|
| 33 | 否 | — | 正常显示时间 |
| 43 | 是 | `(43-3)%10==0` ✅ | **红色 `--:--`** |
| 53 | 是 | `(53-3)%10==0` ✅ | **红色 `--:--`** |
| 47（击杀帧） | 是 | `(47-3)%10=4` ❌ | **直接从槽位消失** |

⇒ 击杀帧**是否**变成 `--:--`，取决于 `(deadTime - Offset) % 10 == 0`；不成立时才会直接从槽位消失。

### 例 B：本模块 20 分钟网格，offset = 7，帧 = 7/27/47/67…，deadTime = 47

`TimelineMirror.Offset` 若仍是 7（与我们的偏移恰好一致）：

```text
num3 = 47 - Mod(47 - 7, 10) = 47 - 0 = 47   // 恰好落在网格上
⇒ num3 == deadTime ⇒ firstHidden 从 {37, 47} 里选
```

| 帧 | 是否在 `_hidden` | `IsRegular` | 结果 |
|---|---|---|---|
| 27 | 否 | — | 正常显示 |
| 47（击杀帧） | 是 | `(47-7)%10==0` ✅ | **红色 `--:--`** |
| 37 | 是（但 37 根本不存在） | — | 无 |

⇒ **击杀帧本身显示 `--:--`**：因为它恰好落在 10 网格上（`IsRegular` 成立），即使 `_hidden` 也照走 `else if`。
其它周期帧（27 等）不在隐藏点里，正常显示时间。

### 例 C：本模块偏移与 `TimelineMirror.Offset` 不一致（offset=7，Mirror.Offset=3）

| 帧 | `IsRegular` | 被隐藏时 |
|---|---|---|
| 27 | `(27-3)%10=4` ❌ | **消失** |
| 47 | `(47-3)%10=4` ❌ | **消失** |

⇒ `--:--` 不仅不出现，连“隐藏后仍保留槽位”的分支都进不去。

### 例 D：`deadTime` 恰好落在网格上（原版）

```text
deadTime = 43, Offset = 3 ⇒ num3 == deadTime
firstHidden 从 {33, 43} 里选
```

- 选 33 ⇒ `_hidden = {43, 33, 43}`（去重后 {33,43}）⇒ 帧 33 是 `--:--`；
- 选 43 ⇒ `_hidden = {43}` ⇒ 击杀帧消失，**没有 `--:--`**。

⇒ 同样是“合法配置”，结果可能是一个提示都没有。

## 3. 当前边界影响（20 分钟录制 + 0–20 偏移）

| 项 | 原版 | 现在 | 后果 |
|---|---|---|---|
| 周期帧网格 | `% 10 == Offset` | `% 20 == ownOffset` | 帧数减半 |
| `IsRegular` 判据 | 硬编码 `% 10 == TimelineMirror.Offset` | 未改（客户端） | 我们的帧经常不满足 ⇒ 被隐藏时**直接消失** |
| 隐藏窗口 | 只含 3 个点 | 未改 | 我们的帧大概率不在这 3 个点里 ⇒ **`--:--` 不出现** |
| 击杀帧 | 独立发送 | 独立发送（未挂钩子） | 不受影响；它显示 `--:--` 还是消失，取决于 `IsRegular(deadTime)` |

**结论**：

1. 时间线的**隐藏/丢失机制本身没被破坏**（那是客户端的），击杀帧也照常发送；
2. 但 `--:--` 这个提示是**按原版 10 分钟网格 + 原版 Offset** 算出来的，我们的 20 分钟网格与独立偏移会让它**基本消失**；
3. 如果希望保留 `--:--`，二选一：
   - 录制保持 `*/10 *` 且偏移范围与游戏一致（0–10）；
   - 或者接受 `--:--` 消失（只是“提示变少”，不影响回放本身）。

## 5. 回放管线（2026-10-26）

服务端对回放帧的所有操作收敛到 `Core/Timeline/Pipeline.cs`（唯一挂点）：

| 阶段 | 挂点 | 处理器 |
|---|---|---|
| Plan | `TimelineRecorder.OnSurvivalTick` Prefix | `ShootReminder`：`RecordCron` + 未报告敏感期抑制 |
| Capture | 预留 | — |
| Transform | `TimelineRecorder.Send` Prefix | `ShadowSabotage`：时钟窗口内缓存/打乱 |

`ShootReminder` 的占位帧在 `StartDetective` Postfix 直接 `Replicator.Participants` 发出，
**不经 `Send`**（避免被时钟破坏的 Transform 缓存）：

- 只对 `CorpseMeta.IsReport == false` 的尸体；
- 时间 = `HiddenWindow.Predict(...)`（与客户端 `TryGetHiddenWindow` 的候选 + `Pick` 逐字一致）；
- 客户端 `IsRegular` 成立 + `_hidden` 命中 ⇒ 红色 `--:--`。

## 6. 泄露防护

未报告尸体的敏感期 `|t - DeadTime| ≤ GuardSeconds`（默认 20）内不采集，
避免出现「不在 `_hidden`、可正常查看」的案发帧。
